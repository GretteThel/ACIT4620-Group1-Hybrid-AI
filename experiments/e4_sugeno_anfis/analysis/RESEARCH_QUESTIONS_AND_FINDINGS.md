# ACIT4620 — E3 versus E4 validation analysis (9 Nov 2026)

**Scope:** Submitted proposal: *A Data-Centric EfficientNet–Neuro-Fuzzy Framework for Skin Lesion Classification: Performance, Explainability, and Computational Efficiency*. These are **validation-only** results from a fixed 7,116-train / 1,441-validation lesion-disjoint split. The separate 1,458-image test set was not used. Report all estimates as exploratory.

## Research-question evidence

**RQ1 — How do controlled data-centric interventions affect macro-F1, balanced accuracy, and recall for underrepresented skin lesion categories?** We audited the full HAM10000 data, retained lesion-disjoint splits, used training-only class weights and augmentation, and performed the ±15° versus ±25° E2b rotation ablation. The E2a-50 weighted CNN achieved validation macro-F1 0.5500 and melanoma recall 43.15% compared with unweighted E1 0.4554 and 19.86%, but E2a-50 also had a longer training budget: effects cannot be attributed to class weights alone. Increasing rotation to ±25° (E2b) gave macro-F1 0.4854 and melanoma recall 39.04%; it did not improve this run. One seed per CNN configuration cannot support universal conclusions.

**RQ2 — Does the proposed ANFIS classifier improve predictive performance relative to linear and parameter-comparable MLP heads on the same CNN features?** The shared input is the exact frozen 1,280-D E2a-50 representation (checkpoint SHA-256 `2efbe67904bed16aec8fbf1f47e3af11f1a0136e7eab4a4c5cbd004edf9b9af9`). All heads use train-only feature normalization, class-weighted loss, and the same validation images. Mean macro-F1 ± sample SD across seeds 42/52/62: linear 0.5417 ± 0.0041, MLP 0.5605 ± 0.0127, ANFIS-4 0.5462 ± 0.0034, ANFIS-8 0.5509 ± 0.0078, ANFIS-16 0.5430 ± 0.0215. The best individual heads (selected on validation macro-F1): MLP seed 42 0.574907; ANFIS-16 seed 52 0.567642; linear seed 42 0.545544. Thus no consistent ANFIS improvement over MLP was established. The selected ANFIS-16 has balanced accuracy 0.6205 and melanoma recall 66/146=45.21%, versus selected MLP 0.5832 and 62/146=42.47%, but MLP has better total accuracy 75.50% versus 72.66%, and better macro-F1. Training optimizers differ (E3 AdamW versus E4 Adam); this is an implementation confound. Macro-F1 best-seed selection reuses validation and must not be described as unbiased test generalization.

**Exploratory paired evaluation** on exactly the same 1,441 validation images and 1,067 distinct lesions. Two thousand lesion-cluster bootstrap samples (stratified by lesion diagnosis, fixed seed 4620) yielded ANFIS-16 seed 52 minus MLP seed 42 macro-F1 difference **−0.00727**, 95% percentile interval **[−0.0522, +0.0510]**. For ANFIS-16 minus linear seed 42, difference **+0.02210**, interval **[−0.0166, +0.0622]**. Both intervals include zero; they are post-hoc conditional-on-fitted-model checks, ignoring seed/model selection and training variability. No significance or superior generalization can be claimed.

**RQ3 — How stable and faithful are class-specific Grad-CAM explanations and signed ANFIS rule contributions?** All nine E4 runs saved normalized rule firing weights, Gaussian premises, class-specific signed rule contributions, and controlled rule deletion (remove high/low absolute contribution to original predicted class and renormalize remaining firing weights). In the selected ANFIS-16 seed 52, removing the most influential rule changed the predicted class for **45.94%** of validation images and changed the original predicted-class probability by **0.4256** on average (absolute). Removing the least influential rule changed none and the mean absolute original predicted-class probability change was only about **4.7 × 10⁻⁸**. This shows model dependence on the rules labeled influential under this intervention. It is **not** independent proof of causal explanatory validity or medical semantics; the max-vs-min comparison is partly expected by how the rules were selected. Grad-CAM through ANFIS logits, image occlusion, visual artifact slice analysis, and explanation stability comparisons remain incomplete. Therefore RQ3 is only partially answered.

**RQ4 — What are ANFIS training, inference, memory costs, and rule-count trade-offs?** Trainable head parameters: E3 linear 8,967; E3 MLP 10,767; E4 R=4 **10,564**; R=8 **10,880**; R=16 **11,512**. ANFIS parameter counts are within ~7% of MLP. ANFIS mean CPU training times across seeds were roughly **3.91 / 4.93 / 4.97 s** for 4/8/16 rules, respectively, on the already extracted features (measured as implemented; not matched controlled hardware benchmarks). E4 reports head-only batch inference around **0.0011–0.0014 ms per image**, which excludes CNN preprocessing/feature extraction, uses large batches and few timings, and must **not** be presented as end-to-end clinical latency or as a fair speed ranking against E3 without an identical benchmark. Peak GPU memory is not measured (CPU run). Increasing rules did not monotonically improve macro-F1: R=8 highest mean 0.5509; R=16 highest selected run 0.5676 but larger between-seed SD 0.0215. End-to-end timing, peak memory profiling, controlled inference benchmarking and image-level XAI remain to be done. Thus RQ4 is **partially answered**.

## Scientific conclusion

The implemented first-order Sugeno neuro-fuzzy head is feasible and inspectable, with classification performance comparable to the linear/MLP heads on identical CNN features; however **ANFIS superiority is not demonstrated**. The MLP has the highest mean and selected macro-F1, while selected ANFIS-16 shows higher balanced accuracy and melanoma recall but more overall errors. The learned fuzzy rules operate in an eight-dimensional latent CNN feature space and are not inherently human-interpretable diagnoses. Avoid clinical claims, claims of statistical superiority, or claims about held-out test performance.
