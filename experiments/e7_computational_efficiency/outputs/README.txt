## ACIT4620 — Notebook 11 Computational Efficiency Results

This directory contains the completed computational-efficiency
experiments using the original saved E2a-50, E3 and E4 checkpoints.

###ACIT4620_11_Efficiency_Results/
    CSV tables, figures, benchmark provenance and memory methodology.

### ACIT4620_11_Efficiency_Results.zip
    Original finalized timing and parameter benchmark results.

### ACIT4620_11_Efficiency_Results_With_Peak_Memory_Fixed.zip
    Finalized timing results and corrected sampled CPU process-memory
    measurements.

All experiments use saved trained models.
The held-out test set was not evaluated.

CPU memory results represent sampled process RSS, not exact
model-specific tensor allocation or guaranteed instantaneous peaks.
